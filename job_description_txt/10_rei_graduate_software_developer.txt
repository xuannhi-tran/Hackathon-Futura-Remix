Description:
REI Cloud is the property management and trust accounting platform built by the team behind REI Master — Australian-owned, 20+ years in the market, used by 1,200+ businesses (holiday letting operators, permanent rental agencies, management rights businesses, serviced apartment groups).

This is a genuine ground-floor opportunity on a small team with no graduate program, no rotation, no shadowing. You'll be given real work in your first week, your code will go in front of real customers.

You'll work alongside developers on:
- Building and shipping features in line-of-business applications used daily by property managers
- Working across the stack — C#/.NET services, React/Angular + TypeScript, Blazor front ends, Azure SQL
- Building and running workloads on Microsoft Azure
- Trust accounting, bookings, channel management, inspections — complex, high-stakes domain logic
- Using Claude Code and AI pair-programming as core to how you work
